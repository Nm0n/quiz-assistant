# 📱 刷题助手

## 📖 项目简介

这是一个新手自用的刷题助手，借助 GitHub 的打包功能将电脑上能运行的应用尝试移植到手机端的项目。

---

## 🚀 使用步骤

1. **准备题库**：将 Excel 中的题库修改成电脑端应用能读取的格式：
   - **必须**：题型（单选题/多选题/判断题）、题干、选项（选项A/选项B……）
   - **非必须**：解析、错题（是）、收藏（是）
2. **转换格式**：通过电脑端应用把 Excel 中的题库保存为 JSON 格式。
3. **导入手机**：在手机上复制 JSON 的文本，通过剪切板导入到移动端的应用中。

---

## ✨ 软件功能

- **三大模式**：全量刷题、错题重做、收藏复习，支持随机刷题。
- **记忆功能**：开启后直接看正确答案和题目解析，方便背题。
- **自由编辑**：可随时标注或取消该题目的错题/收藏属性，可编辑题目解析的内容，方便记录对该题目的想法。

## ⚠️ 存在问题及原因

- 因技术路线采用 **PySide6 + Qt bootstrap**，而 **pyjnius** 只适配 SDL2/WebView bootstrap、**PySide6** 又未把 Qt 自己的 JNI 类型（`QJniObject` 等）绑定到 Python，导致 Python 层没有任何可用的 JNI 桥接手段。因此，虽然 Qt 的 `FileDialog` 能弹出系统文件选择器，但选中文件后返回结果会被 **Activity relaunch** 打断，无法传到 Python，从而导致了 Android 上无法让用户从手机里选中一个 JSON 文件导入到应用。

- 这就是使用步骤如此复杂的原因：不能通过文件选择窗口导入题库，只能通过剪切板导入题库。
